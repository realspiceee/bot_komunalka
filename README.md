# Telegram-бот для отслеживания отключений коммунальных ресурсов по Telegram-каналам с фильтрацией по городу, улице и типу ресурса.

## 🚀 Возможности

- Настройка города и улицы (улица необязательна)
- Выбор ресурсов:
  - вода
  - горячая вода
  - свет
  - газ
  - отопление
  - интернет
- Добавление и удаление Telegram-каналов
- Фоновая проверка каналов по расписанию
- Кнопка **«Проверить сейчас»** — принудительная проверка
- Удобный интерфейс с кнопками
- SQLite для хранения данных пользователей

---

## 🧱 Структура проекта

bot.py # интерфейс бота и кнопки
scheduler.py # фоновая проверка каналов
text_parser.py # анализ текста сообщений
telethon_client.py # Telethon-клиент
database.py # работа с SQLite
config.template.py # шаблон конфига (без секретов)
